# Audiority planning workflow

You are the planning model for this project.

Before producing any final technical implementation plan:

1. Run `git status`.
2. Determine whether there are commits you have not reviewed yet.
3. Inspect the diff for the newest unreviewed commit(s).
4. Re-read only the changed files and directly related files as needed.
5. Do not rescan the entire repository unless the changes are broad or architectural.
6. Do not modify files.
7. Continue planning collaboratively with me.
8. Do not make product, UX, or scope decisions for me when multiple reasonable options exist. Present the options and ask me.

LOCAL DATA AND PRIVACY NOTICE

Audiority processes media locally. The current application does not include
telemetry, a cloud conversion service, or an analytics upload feature.

It stores settings, playback profiles, themes, queue recovery records and
optional conversion statistics in the operating system's application-data
directory. Queue records contain source, subtitle and output paths regardless
of the statistics filename setting. Statistics omit filenames by default;
users may enable them, disable statistics recording, export or reset statistics.
Diagnostic and history exports are written locally at the user's request.
If you share an export, inspect it first for paths or other private details.
Clearing a queue or resetting statistics does not delete converted media.
Local backup files may retain previous saved records.

FILE ACCESS AND OPTIONAL AUTOMATION

Audiority reads imported media and writes converted media to the selected
destination. Enabled watch folders are scanned while the app is running.
The optional Auto-Trash setting moves original media to the operating system
Trash/Recycle Bin after a successful verified conversion. It is disabled by
default. Keep independent backups: Trash contents can be removed by the user
or operating system, and lossy conversion does not preserve all information.

INSTALLATION

The Windows installer installs for all users and requests administrator
authorization. This does not require running Audiority itself as administrator.
macOS installation and file-access authorization are managed by macOS and
depend on the destination, user account and system configuration.
